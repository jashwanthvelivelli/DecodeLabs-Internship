# Project 3 - ATM Interface

## Description

A Java console-based ATM Interface developed as part of the DecodeLabs Internship.

## Features

- PIN Authentication
- Deposit Money
- Withdraw Money
- Check Account Balance
- Transaction History
- Input Validation
- Encapsulation
- Object-Oriented Programming
- Exception Handling

## Technologies Used

- Java
- OOP
- Scanner
- ArrayList

## Project Structure

- BankAccount.java
- ATM.java
- Main.java
