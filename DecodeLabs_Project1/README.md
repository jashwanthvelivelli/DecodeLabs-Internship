## Project 1: Number Guessing Game

### Description
A Java console application where the computer generates a random number between 1 and 100, and the user has to guess it.

### Features
- Random number generation
- User input using Scanner
- Too High / Too Low hints
- Attempt counter
- Score calculation
- Exception handling for invalid input
- Play Again option (Y/N)

### Technologies Used
- Java
- IntelliJ IDEA
